# HiveMind Legacy Archive Overview

**What is this folder?**
This archive contains deprecated documentation, old implementation specs, random script utilities, and media that mark the historical progression of the HiveMind Multi-Agent Reinforcement Learning project.

In an effort to professionalize and streamline the active repository, these files have been safely stored here. They are no longer actively maintained.

## Folder Structure

- `/docs_analysis`: The preliminary, unrefined documentation generated during early architecture analysis and TensorBoard dives. These have been superseded by the highly polished documentation inside `repo_docs/`.
- `/old_reference_and_media`: Contains outdated reference materials (e.g., `TRAINING.md`), original PDF specifications, and early-stage `.gif` demos.
- `Legacy_Overview.md`: This file.

*If you are looking for current architecture, training methodology, or API documentation, please see the `repo_docs/` folder in the root directory.*
